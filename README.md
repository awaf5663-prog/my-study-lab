# My Study Lab

Plateforme d'apprentissage personnelle basée sur la méthode VCR (Visualiser, Comprendre, Restituer).

- Page unique : `index.html` (aucune dépendance, aucun build).
- Les données restent dans le navigateur (localStorage).
- Les fonctions IA (extraction, professeur, examens, correction, vérification de conformité) ne fonctionnent que lorsque la page est ouverte depuis claude.ai. Sur GitHub Pages, le reste fonctionne : parcours V/C/R, révision espacée, mixte, bibliothèque de codes et recherche, planning, progrès.

## Déploiement avec GitHub Pages
1. Crée un dépôt, par exemple `my-study-lab`.
2. Ajoute ces fichiers à la racine.
3. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
4. L'adresse sera `https://TON-PSEUDO.github.io/my-study-lab/`.
